# Text Representation Learning

Experiments on lexical and neural book representations, supervised prediction, and semantic structure.

| Notebook | Study |
| --- | --- |
| [word_embeddings.ipynb](word_embeddings.ipynb) | Skip-gram Word2Vec with negative sampling, Gensim FastText, and optional native FastText. |
| [genre_classification_and_clustering.ipynb](genre_classification_and_clustering.ipynb) | TF-IDF versus sentence embeddings; classification, imbalance handling, and semantic clustering. |
| [bert_adaptation_and_analysis.ipynb](bert_adaptation_and_analysis.ipynb) | Full fine-tuning, LoRA, and a frozen-encoder head; layer-wise representation analysis. |

## Run

Use a dedicated Python environment and launch Jupyter from this directory:

```bash
python -m pip install -r requirements.txt
jupyter lab
```

Word embeddings use `../data/top_3000_rated_books.csv`. Genre experiments require `data/books_with_description_emb.csv`; see [`data/README.md`](data/README.md). BERT requires `../lexical-book-search/preprocessed.json`, generated by the book-search module. GPU execution is recommended for BERT. Native FastText is optional and can be installed with `python -m pip install fasttext`.

Notebooks retain recorded plots, tables, and written analyses. Progress logs and machine-specific metadata have been removed; the recorded results were not rerun during repository preparation.
