# Embedded book descriptions

Place `books_with_description_emb.csv` here for genre classification and clustering. Required columns are `description`, `genres`, and `description_emb`; `title` supports qualitative inspection. The supplied notebook identifies the embedding model as `BAAI/bge-large-en-v1.5` (1,024 dimensions).

This CSV was absent from the uploaded archive. The notebook retains the original optional download cell. Word embeddings use the shared CSV in the repository's `data/` folder, and BERT uses the JSON generated by the book-search module.
